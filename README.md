# Memória Sindical — Raio-X da Luta

Site de memória sindical dos trabalhadores dos Correios: 38 anos de
Acordos Coletivos (ACTs), Dissídios Coletivos (DCs) e conquistas.

**No ar em:** https://github.com/projetosciviltech/Memoria_sindical/

## Estrutura

- `index.html` — hub de apresentação
- `financeiro.html` — evolução do poder de compra (1995-2026)
- `direitos.html` — cláusulas não financeiras por tema e governo
- `assets/` — CSS, JS e identidade visual
- `data/` — JSONs com dados agregados
- `vendor/` — dependências (Chart.js)
